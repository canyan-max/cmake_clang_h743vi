# 服务层规则

- 服务层负责业务流程与初始化顺序，通过稳定的公共 `bsp_*` 能力访问板上设备。
- 保持服务 API 面向业务语义；不要泄露板级引脚、HAL 类型或 MCU 句柄。
- 服务实现保持 RTOS 无关；任务创建、通知和调度策略放在 `01_App` 或 `Core` 的任务入口壳中。
- 涉及帧处理、回调或定时逻辑时，明确调用上下文；ISR 路径只记录事件或通知上层，不执行阻塞操作。
- 允许调用稳定的公共 `bsp_*`；`plat_*` 仅限日志、时基和必要诊断。不得访问 BSP 私有状态、`board_config.h`、CubeMX 或 HAL。
- 只有出现跨设备聚合、复杂生命周期、并发仲裁或可替换设备语义时，才新增独立设备抽象层。
