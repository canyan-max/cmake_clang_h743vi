# 服务层规则

- 服务层负责业务流程与初始化顺序，硬件业务优先调用 `03_Device` 的公开 API。
- 保持服务 API 面向业务语义；不要泄露板级引脚、HAL 类型或 MCU 句柄。
- 涉及帧处理、任务通知或定时逻辑时，明确调用上下文，避免在不允许阻塞的路径中阻塞。
- 允许调用稳定的公共 `bsp_*` 与 `plat_*` 接口，用于日志、时基、诊断、板级状态或其他基础设施能力；不得访问 BSP 私有状态、`board_config.h`、CubeMX 或 HAL。
- 若某个 Service 的核心业务长期直接操作同一外设，应新增或扩展 `device_*` API，而不是持续扩大对 BSP 的直接依赖。
